# Test vectors

Fixed inputs and the results every implementation must give (protocol
draft, [section 11](../docs/protocol-draft.md#11-conformance-artifacts)).
Each file is generated by the crate that holds the format and checked in CI
two ways: regenerating it must reproduce the committed file byte for byte,
and every case must give its recorded result through the code the client
or server runs. Each file's `description` states the rule it pins.

| File | Format | Generated by |
| --- | --- | --- |
| [`labeled-signature.json`](labeled-signature.json) | MLS `SignWithLabel` with the `wr` labels | `quill-certs` |
| [`device-certificate.json`](device-certificate.json) | Device certificates, with must-reject cases | `quill-certs` |
| [`device-revocation.json`](device-revocation.json) | Device revocations | `quill-certs` |
| [`rejoin-request.json`](rejoin-request.json) | Rejoin requests | `quill-certs` |
| [`linking.json`](linking.json) | Linking codes: fingerprint, QR string, 6 words | `quill-core` |
| [`backup.json`](backup.json) | Recovery codes, the backup plaintext, a sealed `age` file | `quill-core` |
| [`attachment.json`](attachment.json) | Sealing and opening attachments | `quill-core` |
| [`ordering-clock.json`](ordering-clock.json) | The hybrid logical clock and display order | `quill-core` |
| [`json-objects.json`](json-objects.json) | Encrypted JSON objects against [`schemas/`](../schemas/) | `quill-core` |
| [`names.json`](names.json) | Tag slugs, channel names, tag namespaces | `quill-proto` |
| [`limits.json`](limits.json) | Default limits, text limits at and past their edge, blob buckets | `quill-proto` |

To rewrite them after a deliberate change, run the crate's tests with
`QUILL_WRITE_VECTORS=1`, and review the diff. The sealed backup is
randomized, so its generator keeps the committed one while it still opens.

Not covered here: the leaf extension (a fixed KeyPackage would expire; the
end-to-end KeyPackage tests cover it) and MLS itself (OpenMLS runs the IETF
test vectors). Checks on WebAssembly builds come with the web client.
