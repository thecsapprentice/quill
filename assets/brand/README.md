# Plait brand assets

The source of truth for Plait's logo, app icon, hero art, interface icons
and illustrations. Every file here is generated by
[`src/build.py`](src/build.py); change the generators, rerun, and commit
the output:

```sh
python3 assets/brand/src/build.py   # needs fontTools, Pillow and rsvg-convert
```

How the rename from Quill applies to the code, and the order to do it in,
is in [`docs/rebrand-plait.md`](../../docs/rebrand-plait.md).

## The idea

Writing together is like weaving. A public prompt is the warp: threads
strung on the loom for others to weave through. A private session is the
loom itself. Each writer is a thread of their own colour, and the finished
piece is one cloth with every colour in it. The mark is a three-strand
**plait**: separate strands that hold together only because they cross.

The weaving is for the art, the brand and the docs. The app's labels stay
in writing words (prompt, session, request, persona, server), and so do
the icon names. See "Vocabulary" in
[`docs/rebrand-plait.md`](../../docs/rebrand-plait.md).

## Palette

The neutrals and the teal are the client's existing tokens
(`crates/quill-ui/src/style.css`), so nothing in the app changes colour.
The other three are new "thread" tokens: one per writer in the art, and
free for the UI to use for writer identity later.

| Token | Light | Dark | Use |
| --- | --- | --- | --- |
| `--accent` (teal thread) | `#0e6c78` | `#5cc3cc` | Existing accent; first strand |
| `--thread-ochre` | `#c27f1d` | `#e8b25e` | Second strand |
| `--thread-madder` | `#b0405a` | `#e37a92` | Third strand |
| `--thread-indigo` | `#3d4f96` | `#8f9fe6` | Fourth thread in the hero and cloth |
| `--ink` / `--paper` / `--line` / `--muted` | existing | existing | Unchanged |
| `--wood` | `#b98a5a` | `#9c7550` | The shuttle in illustrations |

Add the new tokens beside the old ones in each of the three theme blocks
of `style.css` (and `board.css` if the board uses the illustrations):

```css
  --thread-teal: var(--accent);
  --thread-ochre: #c27f1d;   /* dark: #e8b25e */
  --thread-madder: #b0405a;  /* dark: #e37a92 */
  --thread-indigo: #3d4f96;  /* dark: #8f9fe6 */
  --wood: #b98a5a;           /* dark: #9c7550 */
```

The wordmark is set in **Lora** SemiBold (SIL Open Font License) and
outlined to paths, so no font ships with it.

## Interface icons

24 by 24, no fill, 2px round strokes in `currentColor`: the same rules as
the board's existing nav icons (`layout.rs`), so they sit together. Names
and titles are the app's own words; the weaving is in the drawings.

| Icon | Drawn as | Icon | Drawn as |
| --- | --- | --- | --- |
| `home` | House | `persona` | A spool of thread |
| `board` | Prompt cards hung from a beam | `personas` | Two spools |
| `prompt` | A card hung from a beam | `add-writer` | Spool and plus |
| `prompt-new` | Hung card with a plus | `verified` | Shield with a tick |
| `my-prompts` | Two hung cards | `key` | Identity key |
| `request` | A shuttle | `devices` | Linked devices |
| `request-sent` | Shuttle, arrow out | `backup` | Backup and recovery |
| `request-received` | Shuttle, arrow in | `server` | Columned hall |
| `session` | A loom | `federation` | Two linked nodes |
| `session-locked` | Loom with a padlock | `rules` | Scroll |
| `contribution` | A wavy strand | `notices` | Bell |
| `story` | Woven cloth | `news` | Newspaper |
| `planning` | Grid of notes | `tag` | Tag |
| `channels` | Stacked layers | `report` | Flag |
| `export` | A bolt of cloth | `moderation` | Shield with a mark |
| `edit` | Needle | `search`, `filter`, `settings` | As named |
| `attach` | Paper clip | `waiting`, `accept`, `decline` | As named |
| `more`, `sign-in`, `sign-out` | As named | | |

Using them:

- **In Rust (both UIs).** Copy `icons/icons.rs` to
  `crates/plait-board-ui/src/icons.rs` and export it. The desktop UI
  already depends on the board UI, so both share one copy, and the server
  links nothing new (it's path strings). Render with the board's existing
  helper: `svg { view_box: "0 0 24 24", fill: "none", stroke: "currentColor",
  stroke_width: "2", stroke_linecap: "round", stroke_linejoin: "round",
  aria_hidden: "true", path { d: icon.path() } }`.
- **In HTML.** Inline `sprite.svg` once and use
  `<svg class="icon"><use href="#plait-session"/></svg>`.
- An icon next to a text label is decorative (`aria-hidden`). An icon
  alone on a button needs `aria-label` set to its `meaning()`.

## The login hero

The welcome screens (`first_run.rs`, `Card`) are a centred card today.
With the hero they become a split screen when there's room, and a banner
above the card when there isn't:

```rust
// first_run.rs: Card
main { class: "welcome",
    div { class: "hero", aria_hidden: "true",
        div { class: "hero-light", dangerous_inner_html: art::HERO_LIGHT }
        div { class: "hero-dark", dangerous_inner_html: art::HERO_DARK }
    }
    section { class: "card", aria_labelledby: "card-title",
        div { class: "card-band", aria_hidden: "true", dangerous_inner_html: art::PLAIT_BAND }
        h1 { id: "card-title", "{title}" }
        p { class: "lede", "{lede}" }
        {children}
    }
}
```

`art` is a module of `include_str!` constants over this folder's SVGs (our
own files, compiled in, so `dangerous_inner_html` takes no outside input).

```css
.welcome { display: grid; grid-template-columns: minmax(0, 1fr); grid-template-rows: 9rem auto; place-items: start center; padding: 0 0 2rem; }
.hero { width: 100%; height: 100%; overflow: hidden; }
.hero svg { width: 100%; height: 100%; display: block; }
.welcome .card { margin-top: -2.5rem; position: relative; overflow: hidden; }
.card-band { position: absolute; inset: 0 0 auto 0; height: 6px; }
.card-band svg { width: 100%; height: 100%; display: block; }
.hero-dark { display: none; }
.quill[data-theme="dark"] .hero-light { display: none; }
.quill[data-theme="dark"] .hero-dark { display: contents; }
@media (prefers-color-scheme: dark) {
  .quill:not([data-theme="light"]) .hero-light { display: none; }
  .quill:not([data-theme="light"]) .hero-dark { display: contents; }
}
@media (min-width: 900px) {
  .welcome { grid-template-columns: minmax(20rem, 1.1fr) minmax(26rem, 1fr); grid-template-rows: 100vh; padding: 0; place-items: center; }
  .hero { grid-column: 1; grid-row: 1; }
  .welcome .card { grid-column: 2; margin: 0 2rem; }
}
```

(`.quill` becomes `.plait` with the rename.) The `Starting` screen and the
`PreparingStep` ("making the keys") are good homes for
`loader-shuttle.svg`; it stops moving when the system asks for reduced
motion.

## Window icon and packaging

- **Window.** `quill-gui/src/main.rs` builds the window's `Config`. Add
  `.with_icon(icon)` *after* `.with_window(...)` (it writes into the
  window builder that `with_window` sets). `icon` is tao's
  `window::Icon::from_rgba(rgba, 256, 256)` over `png/plait-256.png`,
  decoded at startup with the `png` crate (already in `Cargo.lock`; as a
  direct dependency it needs a `cargo vet` entry), or embedded as raw RGBA
  by a build script to avoid the dependency.
- **Installers.** Windows wants `plait.ico`, macOS `plait.icns`, Linux the
  PNGs (`hicolor/{size}x{size}/apps/plait.png`) with a `.desktop` file
  named `plait.desktop` and `Icon=plait`. Whichever bundler Phase 3
  settles on reads these paths from its config.

## The public board

- Replace the `/favicon.ico` route (it returns 204 today, and
  `quill-e2e/tests/board.rs` checks that) with one serving
  `app-icon/favicon.ico`, plus `/favicon.svg` and `/apple-touch-icon.png`,
  with long cache headers. Add the `link rel="icon"` tags to the board's
  `head` in `quill-board-ui/src/lib.rs`.
- Add `og:title`, `og:description` and `og:image` (`social/og-card-light.png`,
  served from the same origin) to that `head`.
- The board renders without JavaScript, so the illustrations are inlined
  like the GUI's, and the sprite is inlined once per page.

## Rules for new art

- Draw in the generators, not by hand, so a palette change reaches
  everything.
- Thread colours stand for writers, never for status: status keeps the
  existing `--warn` and `--bad` tokens.
- Icons: 24 grid, 2px round stroke, no fills, one path, at least 2px from
  the edge. Check them at 16px and 24px in the sheet before committing.
- Illustrations use tokens with fallbacks (`var(--line, #d9dee5)`), never
  hard-coded colours, so dark mode needs no second file.
